# play-with-box

A simple Hello World web app built with Node.js, deployed to Vercel.

## Stack

- **Runtime**: Node.js
- **Framework**: Express
- **Deployment**: Vercel

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Development mode

```bash
npm run dev
```

## Deployment

This project is deployed to Vercel. Any push to the main branch triggers an automatic deployment.
